# ITIS Schedule → Календари (.ics)

Генерирует `.ics`-календари из [расписания ИТИС (Google Sheets)](https://docs.google.com/spreadsheets/d/12m_Ze1NOnVvdVuSDY5bj0v4r24xLY5RhtuBxNjS26yQ) для каждой группы.
Персональные календари студентов 4 курса выкидывают невыбранные элективы по [распределению КВ](https://docs.google.com/spreadsheets/d/1ylZLNeuGEpb_7lVqtRlOfs6ngj_c977Zgt5XKZf_aSc).

> 🌐 **Проще всего — через сайт:** поиск по группе, кнопка «Копировать», проверка персональной ссылки.
> Открыть: **https://renattele.github.io/itis-schedule/**
> (Таблицы ниже — та же информация текстом, для копирования без сайта.)

## Как подписаться (1 минута)

1. Скопируй ссылку своей группы (на сайте кнопкой, или из таблицы ниже).
2. **Google (только с компьютера — мобильное приложение подписку по ссылке не добавляет):** кнопка **Google** на сайте, либо вручную [calendar.google.com → Подписаться по URL](https://calendar.google.com/calendar/u/0/r/settings/addbyurl?pli=1) → вставь → Добавить календарь. События могут подтянуться с задержкой до 24 часов — это нормально.
3. **Apple:** вставь ссылку как «Добавить календарь по ссылке» (или открой `webcal://…` ссылку с сайта).
4. **Outlook:** кнопка Outlook на сайте, либо подписка по URL.

## Другие варианты календарей

Шаблон — заменяешь `unified` / имя файла:

```
https://cdn.jsdelivr.net/gh/renattele/itis-schedule@calendars/<тип>/<файл>.ics
```

- **Только лекции:** `groups/lectures/<группа>.ics`
  <br>Пример: `https://cdn.jsdelivr.net/gh/renattele/itis-schedule@calendars/groups/lectures/11-501.ics`
- **Только практики:** `groups/practices/<группа>.ics`
  <br>Пример: `https://cdn.jsdelivr.net/gh/renattele/itis-schedule@calendars/groups/practices/11-501.ics`
- **Без переименований предметов (`overrides.json`):** `groups/without_overrides/unified/<группа>.ics`

У магистратуры 1 курса (`11.1-521` … `11.1-571`, `11.1-651`, `11.1-652`) есть только практики — отдельных файлов лекций для них нет.

## Персональные календари студентов

Файл студента: `students/unified/<группа>_<Фамилия_Имя_Отчество>.ics`, например:

```
https://cdn.jsdelivr.net/gh/renattele/itis-schedule@calendars/students/unified/11-601_Иванов_Иван_Иванович.ics
```

Не помнишь точное имя файла — просто введи фамилию в поиск на [сайте](https://renattele.github.io/itis-schedule/): покажет твой персональный календарь с кнопками подписки. Вручную: [папка `students/unified` в ветке `calendars`](https://github.com/renattele/itis-schedule/tree/calendars/students/unified) → `t` → фамилия → `Raw` → скопируй URL.

Аналогично есть `students/lectures/`, `students/practices/` и `students/without_overrides/`.

## Для разработчиков

Таблицы выше и снапшот сайта генерируются скриптом из реального состояния ветки `calendars` — руками их править не нужно:

```bash
python -m src.sitegen            # скан origin/calendars → README.md + docs/index.html
python -m src.sitegen --calendars-dir ./calendars   # локальная папка (используется в CI)
```

Сайт — один файл без зависимостей (`docs/index.html`): при загрузке показывает встроенный снапшот, затем в фоне подтягивает свежий список через GitHub API.

### Запуск через Docker

```bash
docker build -t itis-schedule .
docker run --rm \
  -v $(pwd)/calendars:/app/calendars \
  -v $(pwd)/overrides.json:/app/overrides.json \
  itis-schedule \
  --split-types \
  --overrides /app/overrides.json
```

### Переименования предметов (`overrides.json`)

Ключи — регулярные выражения по названию предмета:

```json
{
  "Технологии разработки ПО.*Kotlin.*": {
    "subject": "KMP Development",
    "link": "https://example.com/new-kotlin-link",
    "notes": "Custom notes for this subject"
  }
}
```

| `--choices-gid` | все вкладки | GID вкладки с распределением (можно несколько раз) |

### GitHub Actions

Воркфлоу [`.github/workflows/generate.yml`](.github/workflows/generate.yml) запускается **каждые 5 часов** и вручную:
1. Собирает Docker-образ, прогоняет тесты.
2. Генерирует `.ics` для всех групп и студентов.
3. Обновляет `docs/index.html` (снапшот), копирует сайт в `calendars/index.html`.
4. Публикует всё в ветку `calendars` (там же лежит сайт для GitHub Pages).
5. Обновляет таблицы в `README.md` на `main`, если состав групп изменился.
